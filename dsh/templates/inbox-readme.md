# 备忘录库 · inbox 说明

> 本目录由 AI 自动维护：捕捉“一般性的数学思路、方法、技巧、观点”（新 memo 经你同意后创建），并跟踪每条想法的生命周期：
> `inbox`（待打磨）→ `polishing`（打磨中）→ `done`（已归入正式笔记）。
>
> - 每条想法一个 md 文件（`<slug>.md`），状态写在 frontmatter；
> - 总清单在 [`index.md`](index.md)，按状态分组；
> - AI 会在“出现新关联想法/证据”或“条目久未更新”时主动提醒你打磨。

## 单条 memo 模板

```markdown
---
title: <想法名>
tags: [想法/待打磨]
status: inbox            # inbox / polishing / done
created: YYYY-MM-DD
updated: YYYY-MM-DD
last_reminded: ''        # AI 每次提醒后写当天日期，用于每天最多提醒一次
topic: <对应主题或“未归类”>
related: []              # 相关 memo/笔记双链：[[slug]]、[[笔记名]]
---

# <想法名>

## 想法
<一两句话的精确陈述>

## 为什么值得捕捉
<可迁移性、与已有主题的关联>

## 关联观察
<每次出现相关证据/想法就追加：日期、新证据、新角度、来源>

## 待打磨
- [ ] <要澄清/证明/泛化的点>

## 打磨记录
<打磨时追加：日期、本轮做了什么、下一步>
```

## 维护规则（AI 执行）

1. **不重复建卡**：新想法与已有 memo 高度相关时，并入其“关联观察”，而不是新建。
2. **双向关联**：相关 memo 之间互相在 `related` 加双链；打磨完成时在 `related` 加正式笔记链接。
3. **状态流转**：每次打磨后更新 `status` 与 `index.md` 分组。
4. **提醒记录**：每次主动提醒后更新 `last_reminded`；默认每条每天最多提醒一次。
5. **不删除历史**：done 的 memo 保留原文与打磨记录，作为想法的完整档案。
