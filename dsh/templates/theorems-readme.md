# 定理索引层说明（个人 Matlas）

> 本目录是本 vault 的**个人定理检索层**（借鉴 Rethlas 的 Matlas 定理搜索引擎）：把笔记中已记录/已证明/未证明的定理、命题、引理、定义登记成可检索目录。
> 与远程数学数据库不同，这里只收录**你 vault 里已有的内容**，所以检索零成本、完全本地。

## 登记条目模板（`theorems/index.md` 中一行）

```markdown
- [[笔记名#定理名|定理名]] · 领域:实分析 · 关键词:紧算子, 谱 · 状态:已证/待证/引用
```

## 登记规则（AI 执行）

1. **什么时候登记**：在对话或笔记中出现新的重要定理/命题/引理/定义，或证明了一个新结果、标记了一个待证猜想时。
2. **状态**：
   - `已证`：本 vault 中有完整证明（或指向权威来源）；
   - `待证`：猜想/未闭合断言（在笔记中标注 `待补`）；
   - `引用`：从外部引用、尚未在 vault 内展开证明。
3. **检索纪律（吸收 Rethlas 的 Search relevant results）**：
   - 证明问题时先查本索引，再 grep 笔记全文；
   - 找到的定理要**展开定义、核对在当前假设下是否适用**，并显式说明术语在不同语境中的差异；
   - 不只读定理陈述，还要读其证明，提取可迁移的技巧、归约与证明模式；
   - 找不到就明说“本地索引没有”，不要编造出处。
