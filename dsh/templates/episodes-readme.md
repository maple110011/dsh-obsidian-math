# 事件卡说明（证据层）

> 本目录是记忆的**原始证据层**（append-only）。AI 每轮对话收尾前先在这里追加事件卡，再去更新 profile/topics。
>
> 设计依据：arXiv:2606.24775 的发现——保留原文/轻压缩优于抽象摘要（M1），写时保留优于早过滤（M2），时间戳多版本优于删除（M4）。

## 文件与追加规则

- 同一天的事件追加到当天文件 `YYYY-MM-DD-<slug>.md`；跨天开新文件。
- 同一文件内每个事件一个 `##` 小节，按时间顺序追加，**不重写已写内容**。
- 事实被推翻时：在新事件里写更正，旧小节保持原样。

## 事件卡模板

```markdown
## HH:MM <一句话标题>

- 用户原话/关键表述：<保留原句，宁多勿删>
- 结论/产出：<本轮的实质结论，保留关键细节与数字>
- 事实修正：<旧事实 → 新事实；无则省略>
- 涉及：[[笔记名]] · 主题：<topic> · 想法：[[YYYY-MM-DD-idea-slug]]（如有）
```

## 容量与归档

- `index.md` 每行一条：`- [[YYYY-MM-DD-slug|标题]] — 主题A、主题B`。
- 目录超过约 40 个文件时，把最旧文件原样移入 `archive/`（不摘要、不合并），并更新 index 链接。
