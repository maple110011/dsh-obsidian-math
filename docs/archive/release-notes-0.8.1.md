## [0.8.1] - 2026-10-05

> 本版主要包含四个方面：**记忆卡开始记录来源**（这张卡是人写的还是助手写的，此前只记"是否核实过"），**笔记里助手补写的段落与尚未定稿的内容会在搜索结果中标明**，**助手不再每轮自动把对话整理成记忆卡**，以及一批针对 **dsh 0.2.0-rc.2** 的修复。⚠️ 本版**重装或重启后生效**；首次体检会给已有卡片补上来源一行（可撤销）。

### Added

- **记忆卡开始记录「来源」**——记录是人写的、助手写的、还是外部导入的。此前只记录"是否核实过"，于是一条助手写的内容可能被当成用户的原话引用。这个字段由插件写入，助手不能写；已有卡片先显示"来源未知"。**它不影响搜索结果的顺序。**
- **笔记里由助手补写的段落会被标出来**——一篇笔记里可能既有用户写的部分、也有助手补写的证明或定义，此前搜索看不出区别，助手补的内容和用户原文一样被返回、一样被当成用户的话。现在搜索结果会注明一篇笔记里有多少处助手补写的内容，体检也会单列一份名单。
- **搜索结果会提醒哪些内容还没定稿**——笔记里带"待核对/待补"这类标记，或含助手补写的段落时，搜索结果会连同这些标记一起说明，助手据此重新推导，而不是把一篇旧笔记当成结论直接复述（同一篇旧综述被反复当成结论使用，是助手回答雷同的常见原因）。

### Changed

- **助手不再每轮自动把对话整理成记忆卡**——此前每轮结束都会把对话内容整理成卡片或索引行。现在**未经用户同意，助手不会写这类内容**；要不要记会**与已有的提问合并成一次**询问，所以弹窗不会变多。用户当场说"记一下"，或此前给过长期授权，才会直接写入。**"这次没记"没有损失**：整场对话原文仍由插件自动保存。
- **"别处也提到了同一个模式"不再自动算作"互相印证"**——那份文档若与卡片**出自同一个来源**，只是同一件事被写了两遍，**不算第二个见证**，可信等级不升；体检会把这种情况单列出来。
- **README 两版写明"已在 dsh 0.2.0-rc.2 上实测"**，版本下限仍留在 `>=0.1.7-rc.2`。

### Fixed

- **"工具返回值经过 dsh 校验器校验"此前是假的绿**——唯一执行这项校验的断言被一个不存在的路径挡住，**整块跳过**却仍报 `9/9`。现在按候选顺序查找，找不到就明确跳过并写明原因。
- **"按插件自己的指示改配置"不再让检查一直报错**——安装清单把 dsh 设置面板**本来就会重写**的配置文件当成了固定文件，于是用户保存一次设置，校验摘要就永久过期并被当成故障。现在区分"安装器私有"与"共享"：共享文件不做摘要校验、卸载时无条件保留；**不用重装**即已恢复正常。
- **老版本装过的 profile 不再静默失去"默认预设"**——0.1.5 时代的遗留配置行在 0.2.0 里已不存在，而匹配不到时 dsh **只警告并跳过**，于是"默认预设"静默失效且没有任何报错。现在安装和引导会把它迁移成现行配置（内容保留、重复执行安全）。
