# 宣传文案存档

本目录存放发布宣传稿（最新：`推文-0.7.5.md`；更早：`推文-0.7.1.md`）。放在根目录时它们占据的是**入口文档**
（README / ARCHITECTURE / CHANGELOG / AGENTS）的位置，而它们其实是归档件。

> **为什么新克隆里可能只有这个文件**：`.gitignore` 的 `推文-*.md` 规则（第 23 行）会忽略
> 本目录下的宣传稿——它们是维护者本地的文案，**刻意不入库**。因此引用它们的文档只是
> **散文提及，不是可点击链接**（2026-09-11 实测：全仓 0 处指向它们的 markdown 链接）。
>
> 如果你要把某份宣传稿纳入版本控制：在该文件的路径上放行 `.gitignore`（例如加一条
> 取反规则），并确认引用处改成真正的链接。
