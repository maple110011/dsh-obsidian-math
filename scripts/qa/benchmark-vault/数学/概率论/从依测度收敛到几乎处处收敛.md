# 从依测度收敛到几乎处处收敛

一个经典问题：若 $X_n \xrightarrow{P} X$（依测度/依概率收敛），能否加强到 $X_n \to X$ 几乎处处？一般不能，但**总存在子列几乎处处收敛**。关键工具是 Borel-Cantelli 引理。

>[!theorem] Borel-Cantelli（第一引理）
>若事件列 $\{A_n\}$ 满足 $\sum_n P(A_n) < \infty$，则 $P(A_n \text{ i.o.}) = 0$。

做法：由 $X_n \xrightarrow{P} X$，对 $\varepsilon_k = 2^{-k}$，取 $n_k$ 使 $P(|X_{n_k} - X| > 2^{-k}) < 2^{-k}$。令 $A_k = \{|X_{n_k} - X| > 2^{-k}\}$，则 $\sum_k P(A_k) < \infty$，由 Borel-Cantelli，$P(A_k \text{ i.o.}) = 0$，即在几乎每个 $\omega$ 上，$k$ 足够大后 $|X_{n_k} - X| \le 2^{-k}$，故 $X_{n_k} \to X$ a.s.。

>[!tip] 快子列技巧
>选子列时让"误差"与"概率"都按几何级数衰减（$2^{-k}$），这样概率和才收敛，Borel-Cantelli 才用得上。选得太慢（如 $1/k$）概率和发散，引理失效。
