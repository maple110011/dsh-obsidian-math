# 对角线选取方法

**原理**：有界必有收敛子列（Bolzano-Weierstrass）；可数稠密集上逐点收敛。

**形式**：对一致有界的函数列 $f_n$，在可列稠密集 $\{q_1,q_2,\dots\}$ 上逐点选取子列：
1. 因 $\{f_n(q_1)\}$ 有界，取收敛子列 $f_{n_{1,k}}(q_1)$；
2. 因 $\{f_{n_{1,k}}(q_2)\}$ 有界，取子列 $f_{n_{2,k}}$ 在 $q_1,q_2$ 处均收敛；
3. 反复进行，第 $k$ 个子列在 $q_1,\dots,q_k$ 处收敛；
4. 取对角元素 $f_{n_{j,j}}$，则在所有 $q_i$ 处收敛。

**作用**：用可数控制不可数——在稠密可列集上建立性质，再推广到全空间。

**经典战役**：[[从依测度收敛到几乎处处收敛]]（Borel-Cantelli 子列也是同一套路）
