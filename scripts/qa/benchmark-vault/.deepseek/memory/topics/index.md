# 研究主题索引（导航层）

## 使用说明

条目模板：

```markdown
## <主题名>

- 标签：#标签1 #标签2
- 状态：活跃 / 暂停 / 已收束
- 最新状态截至：YYYY-MM-DD
- 核心笔记：[[笔记名]]
- 一句话概括：……
- 详情：[[topics/<slug>]]（细节、开放问题、相关想法）
```
