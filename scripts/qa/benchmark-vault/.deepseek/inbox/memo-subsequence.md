# 子列论证的普遍性

## 想法

「先取子列、再加紧」似乎是一个跨场景的通法：依测度→a.s. 用 Borel-Cantelli，Helly→Prokhorov 用胎紧，都是同一个套路。值得整理成一条通用原则。

## 关联观察

- 「先取子列、再加紧」是定义层证明破局的**等价刻画**家族一员：逐点/逐字展开太繁时，用子列判据换一个更易验证的刻画（依测度→a.s. 用 Borel-Cantelli 即一例）。讨论见策略卡 [[strat-definition-proof]]。
