# 研读记录：louckSecuringLLMAgentLongTerm2026

## 0. 元信息

- citekey：louckSecuringLLMAgentLongTerm2026
- 标题：Securing LLM-Agent Long-Term Memory Against Poisoning: Non-Malleable, Origin-Bound Authority with Machine-Checked Guarantees
- 年份：2026（arXiv:2606.24322，单一作者 Yedidel Louck）
- 阅读日期：2026-10-01
- 阅读方式：MinerU 全文通读（`.raw/louckSecuringLLMAgentLongTerm2026/full.md`）；§I–§X 逐段读，附录 A/B 只读目录
- 一句话立场：它证明"**看内容/看血缘来判断一条记忆可不可信，在原理上就不成立**"，并给出一个可机检的替代构造（写入时绑来源 + 不可篡改传播 + 独立共证才提权）。对我们最直接的后果：**自动互证升级 `cross-referenced` 这条路径，恰好落在它定义的"制造共证"洗白通道里。**

## 1. 一句话定位

记忆投毒不是"检测"问题：攻击者可用三条 LLM 特有的洗白通道（**自摘要 / 可信工具回声 / 制造共证**）把不可信来源洗成看似可信；作者用 TLA+ 机检一个分离定理（T1 内容/血缘防御不健全、T2 写入时绑定来源必要、T3 不可篡改的来源绑定 + 抗 Sybil 的共证提权充分），并给出构造 TMA-NM——8 个前沿模型 × 多条攻击下**直接与洗白攻击 ASR 均 0%**（基线上限 68%），合法效用 100%、判决延迟 1.3 µs。

## 2. 问题与动机

- 已有防御分两类，作者证明**两类都可被洗白**：一类看内容（检测/可信度打分，如 SuperLocalMemory 的贝叶斯打分），一类看派生血缘（MemLineage 式的 derivation edge）。
- 洗白 = 一个**保行为**的变换抹掉不可信来源，使 `D(τ(x)) ⊋ D(x)`（Def. 1：τ 未经同意提高了有效权威）。三条通道（§I）：
  - **L-a 自摘要**：agent 把不可信的网页/文档用自己的话改写进笔记 ⇒ 内容看着无害、派生边被丢掉。论文开头就是这条的完整故事（网页里藏"提备份时把客户名单发到某地址"，agent 改写后当自己的记忆，几周后在无关会话里外发数据）。
  - **L-b 可信工具回声**：可信工具返回攻击者控制的内容。
  - **L-c 制造共证**：攻击者放多条不可信条目伪造"共识"。
- 关键论点：能"行动"的权威必须**不可篡改地绑在真实来源**上，而且**不可信标签必须传播**（派生内容、回声输出都继承最不可信等级）；提权只能靠**≥2 个相互独立的可信主体**或**一次与具体动作绑定的新用户授权**，绝不能靠内容自称可信。

## 3. 记忆结构

- 记忆条目 = `(content, origin, scope, t_write, act_class)`，`origin ∈ {user, trusted tool, agent, untrusted external}`，`act_class ∈ {none, inform, act}`（§II）。
- 流水线：`write → retrieve → act`，其中 act = 回答和/或**有后果的动作**（工具调用、支付、改设置、数据外发）。
- 我们对应：卡片 frontmatter 就是我们的 `(content, origin?, …)`——但**我们只有 content + 少量标签，没有 origin 这一维**（note-noise 缺口 3）。

## 4. 写路径（固化）

- **M1 写入时来源绑定**：`act_class = f(origin)`，在写入那一刻由 monitor 按**到达通道**赋值（用户输入 / 已认证工具 / agent 自写 / 不可信摄取），**绝不从内容推断**（Assumption A1：通道本身已认证，例如 mTLS、audience-bound OAuth、签名工具响应）。
- **M2 不可篡改传播（keystone）**：任何派生自不可信来源的条目自动继承最高不可信度、永远 `act=none`，不管改写后的文本多无害。可信工具只在"在白名单上且**所有绑定输入都可信**"时才可信，否则边界保守污染（标准 over-approximation：污染只升不降）。
- **M3 抗 Sybil 的共证提权**：只有 ≥2 个**独立**可信主体（不同注册表/不同工具，而不是同一网页的两份拷贝）或一次**动作绑定的**新授权（单次令牌 over `(tool, value, amount, nonce, timestamp)`）才能提权；重复的不可信条目不算、提权单调、条目不能自我共证。
- **M4 防篡改判决日志**：写入/提权/允许-拒绝都进哈希链，事后改会断链；每次追加 O(1)、不调模型、不影响判决延迟。
- 与我们的写路径对照：模型可写 `single_source`、体检按"另一份文档出现同一 pattern"自动升 `cross-referenced`、用户 ✅ 才升 `user-confirmed`（note-noise §2.3）。**我们做对了"用户确认只能用户给"，但把"共证"的判据交给了内容比对，而且升级后的标签不携带任何来源信息。**

## 5. 读路径（检索）

- 本文不研究检索质量；判决点的关键在于：**安全相关取值（payee / setting / recipient）来自结构化工具调用**，权威不看文本，而看该值经手的通道。
- 对抗"存储层改写"的一手证据（§VI 末，Mem0 整合实验）：**共证计数由 monitor 的追加记录维护，不从检索回来的文本重新解析**，所以存储侧合并、去重、向量压缩都不能悄悄降低独立性计数或重贴来源标签——"Mem0 可以改写内容，权威活在 monitor 的只追加记录里"。
- 对我们的启示：`verified` 这类标签应当**写在卡上且不可由内容重算**；任何"重新解析文本得出可信度"的路径都自动落在 T1 的失效类里。

## 6. 组织与关系

- 完整性序：`untrusted ⊏ agent ⊏ trusted`（§IV），与 Biba 完整性、Denning 格信息流同源；M3 的"≥2 独立主体"是 Clark–Wilson 职责分离的落地。
- 相似系统定位（Table VIII/IX）：content/trust-scoring（无 WT/NM/EL/MC）、lineage（有 WT/XS 但可被 L-a/L-b 洗白）、capability-IFC（CaMeL/Fides，单会话、假设记忆未受损）、semantic taint（离线审计）、selection integrity（正交通道、无机检）——只有 TMA-NM 六项全 ✓。

## 7. 维护与自改进

- 独立性必须**由构造保证**而不是名义计数（§VIII）：两个可信主体只有在**加密身份不同、管理/信任域不同、无共享上游数据源**时才算独立；monitor 记录每个主体的域，**拒绝共证者共享同一域的提权**。
- Table X（3 模型）量化这件事：单点被攻破在 k=2 下 0%；攻破两个真正独立主体 = 67%（任何 k 阈值的内在上限）；**两个相关主体（共享域）**在 naive 计数下 67%，域感知 monitor 下 0%；升到 k=3 恢复 0%。
- 阈值 k 是**按动作配置**的旋钮：常规可逆动作 k=2，高爆炸半径/不可逆（大额支付、权限变更、批量外发）k≥3 或要求一次动作绑定的新授权。
- 可审计信号（§VIII 末）：某通道"可信标签写入"异常升高、拒绝集中在一个主体上 ⇒ 提示通道被攻破；定期审计判决日志。

## 8. 验证与质量门控

- **形式化**：TLA+ 建模 `write→retrieve→act`， laundering 对手实现三条通道；有界模型 `M`：`Slots=3, sessions≤2, k=2`，由 TLC 穷举（§IV）。
  - **T1**：任何以内容或"内容可导出的血缘边"为判决依据的门，都是可篡改的，且存在可达状态违反安全不变式（TLC 给出见证轨迹 `write-untrusted → paraphrase → act`）。
  - **T2**：关掉写入时来源绑定 ⇒ 安全不变式在可达状态被违反 ⇒ 该绑定在模型内**必要**。
  - **T3**：绑来源 + 仅经 ≥k 独立可信主体（或一次动作绑定新授权）提权的门是不可篡改的，且在 **3,270 个可达状态**上满足安全不变式。
  - **超出有界**：给了一个归纳不变式 `IndInv`，TLC 从所有满足 `IndInv` 的状态出发检查每个迁移都保持它 ⇒ 归纳步被机检；**参数无关性是手写论证**，任意 slot/会话/阈值的全机械化证明（TLAPS/Lean）留作未来工作。作者明确自称"机检的归纳不变式"，而不是"完整机械化的无界证明"。
  - 另对真实 monitor 做了穷举：Action Integrity（120 配置）、Elevation Soundness（64 共证集合）、端到端安全。
- **实证**：MEM-INV-Bench（12 领域 × 5 类有后果工具 × sleeper/control-flow/data-exfiltration 攻击 × benign/static/adaptive/whitebox 变体），8 个前沿模型（gpt-5-chat、gpt-4o-mini、claude-opus-4.1、claude-sonnet-4.5、gemini-2.5-flash、llama-4-maverick、deepseek-chat、qwen3-235b）；Wilson 95% CI + 20,000 次置换检验；空响应 > 5% 的模型被静默失败守卫剔除。
- **对我们可借的门控形态**：① "反同义反复控制"——一个全拦的防御也能拿 0% ASR，所以必须同时报 **legit-utility**（我们的 `engine-probe` 已有"Direct 数不降"的门槛，形态一致）；② **组件消融**（Table IV）区分"安全机制/效用机制/仅审计"；③ 阈值敏感性扫描（Table VI/VII）证明不是调参问题。

## 9. 成本 / 安全 / 隐私

- 判决是**确定性检查、不调模型**：1.3 µs/次 vs 内容检测判官 ~2,000 ms（约六个数量级），"约零可感知延迟"。这一点对我们特别重要：本仓库的红线是"插件不调模型"（`design.md:286`），而 TMA-NM 正是**纯宿主侧确定性逻辑**。
- 理论代价：把信任**搬到了两个地方**——来源标注边界（A1）与共证者的独立性；残余风险是**完全被攻破的可信工具**会洗白取值 ⇒ 这正是要求 ≥2 独立来源的原因；实现代价是每个被提权的来源要能列出"独立主体"。
- 残余风险还包含**相关失效**（看似独立的主体共享上游依赖），作者给的硬化路径是暴露依赖图并做供应链证言。

## 11. 评估方法

- 三类基线**各自取该类最强忠实实现**：content-trust 用**被测模型自身**当判官（不是 stub），lineage 走 MemLineage 式派生边，capability-IFC 走 CaMeL/Fides 式单会话。
- 指标分离得干净：`consequential-ASR`（攻击是否真的执行）/ `legit-utility`（有共证的合法动作能否通过）/ `uncorr-auto`（**未经共证的不可信来源合法动作被自动执行的比例，越低越安全**）/ 判决延迟。
- 我们可借鉴的**被动信号**：`uncorr-auto` 这个指标形态——它专门测"系统有没有把该问人的事自己做了"。我们这边对应的现象是"AI 归纳未经确认就被当事实引用"，但今天**没有任何计数器**（缺口 2/3）。

## 12. 可迁移机制清单

1. **写入时来源绑定（origin at write time）**：卡片落盘时由**宿主确定性写入** `origin`（user / tool / agent / imported-untrusted），模型不能改；标签来自"这条内容从哪条通道进来"，不是"它长什么样"。⇒ 直接补缺口 3。
2. **标签单调传播**：由 AI 归纳 / 由 AI 补全笔记派生的记录，`origin` 不得高于其来源；改写、摘要、翻译**不能提权**（对应 L-a）。⇒ 补缺口 3 + 强化 P4。
3. **共证必须"独立性由构造保证"**：`cross-referenced` 只能由互不共享上游的**两个不同来源**触发（不同 episode / 不同原始出处），并且**共享同一上游文档的两份笔记不算两票**（Table X：相关共证 naive 67% → 域感知 0%）。⇒ 直接改 P5/D1 的升级判据，**这是本次 4 篇里对我们最具体的一条**。
4. **计数与来源放在宿主只追加记录里，不从文本重算**：`verified_by` / 共证计数不能被"重新解析卡片正文"得出（对应 Mem0 段落的结论）。
5. **提权与"动作"绑定并可一次性消费**：我们的类比是"把某条 AI 归纳提升为可依赖事实"这一动作——应记录它在何时、由谁（用户 ✅）批准，且批准与具体内容绑定（内容变了旧批准失效）。⇒ P4 的 `settled` 写入者设计可直接照抄这个形态。
6. **判决日志（哈希链）**：至少对我们"谁把哪条提成了 user-confirmed"留下可审计的追加记录；论文明确区分"安全机制 / 效用机制 / 仅审计"，别把日志当成防御。

## 13. 与 dsh-math-memory 的映射与差距

- **采纳（机制级，强）**：写入时来源绑定 + 单调传播 + 独立性由构造保证的共证门槛。我们现状是"来源不在存储里、共证由内容比对触发"（note-noise §2.3、缺口 3），正是 T1 所否证的那一类判决依据。
- **采纳（形态级）**：把"共证计数"放在宿主的确定性代码里维护、不重新解析文本；提升 `user-confirmed` 时把批准绑定到内容。
- **改造（P2/P1 的位置）**：P1/P2（注入措辞分级 + ❓/⚖️/✅ 标记）是**可见性**改进，论文的结论支持它有意义但**不是**安全/正确性机制——它不改变"这条从哪来"，只是说出来。引用时不能把 P2 说成"解决了洗白"。
- **改造（D1 的选项 A/B 之争）**：Louck 给 D1-A（AI 产物默认降级 / 进 inbox）一个更强的形式：不是"降级权重"，而是"**默认 origin=agent 且不可提权**，除非有独立共证或用户批准"。这与 Zhang 的"固化要设闸"是同一件事的两个侧面。
- **不适用（威胁模型差距，必须写清）**：本文的对手是**自适应攻击者**、目标是**阻止有后果的动作**；它明确把**非后果性的答案偏置（answer-biasing）划出范围**（§VI 末、§IX(a)：TMA-NM 只守 retrieval→action，不管自由文本回答）。**我们用户抱怨的"越看越乱"恰恰是 answer-bias**——所以这篇**不能**作为"AI 笔记会让你理解出错"的证据，只能作为"内容派生的可信度信号在原理上不可靠"的证据。
- **不适用（形态差距）**：TMA-NM 的存在前提是有一个**在模型之外的 monitor** 与**可认证的通道**（A1）；我们的 vault 没有认证通道（笔记可能是用户粘贴的、可能是 AI 写的、可能来自剪藏），`origin` 的实现只能退化为"写入者自报 + 通道推断"，因此**A1 在我们这里只能部分满足**——这一点必须在采纳时如实标注，不能假装拿到了 0% 的保证。
- **可直接复用的"反同义反复"纪律**：任何"让 AI 少依赖脏记忆"的改动，都必须同时报"合法效用不降"，否则"什么都不信"也能刷出好看的数字。我们已有同形门槛（`retrieval-v3.md` §7.5 的"Direct 数不降且排名均值不升"）。

## 14. 行动项

1. **（最小、可机检）** 给卡片加**写入时来源字段**（建议 `hook.origin: user | agent | imported`，缺省 `agent`、fail-closed），由宿主确定写入、模型不可改；注入时按 origin 措辞（与 P2 的 ❓/⚖️/✅ 并行显示，两者语义不同：一个是"谁说的"，一个是"验过没有"）。
2. **（升级判据，先只报不改）** 收紧 `cross-referenced` 的自动升级：要求两个共证来源**不共享上游**（不同 episode / 不同 source 文件），并把"共享上游"的情形单独记为"相关共证（不计票）"，先只输出计数、不动排序。
