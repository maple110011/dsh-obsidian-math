# 研读记录模板（单篇）

> 用途：每篇文献一份，按下面维度记录。目标不是复述全文，而是回答两件事——「这篇能给我们什么可迁移机制」与「我们与它的差距在哪」。读完把卡片 status 置为 distilled，并把精简版写进卡片「核心机制 / 方法」与「与我的工作 / 记忆的映射」两节。

## 0. 元信息

- citekey / 标题 / 年份
- 阅读日期
- 阅读方式：MinerU 全文通读（.raw/<citekey>/full.md）

（解决什么问题 + 核心主张，1-2 句）
